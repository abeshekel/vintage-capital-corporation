# Vintage Capital Corporation Website

This is a free, static, multi-page website template for Vintage Capital Corporation.

## Included pages
- `index.html` — Home
- `about.html` — About Us
- `company.html` — Company profile, mission, principles
- `investment-focus.html` — Sectors and investment focus
- `acquisition-criteria.html` — Target profile and transaction situations
- `approach.html` — Acquisition and growth approach
- `contact.html` — Contact form template
- `styles.css` — Site styling
- `script.js` — Mobile navigation and reveal animation

## Before publishing
1. Replace `info@vintagecapitalcorporation.com` in `contact.html` with your actual email.
2. Review all copy and remove or adjust anything that is not accurate.
3. Add leadership bios when ready.
4. Add a logo if you have one.
5. Replace the contact form with a real form backend if you do not want to use `mailto:`.

## Free hosting with GitHub Pages
1. Create a GitHub account.
2. Create a new public repository named something like `vcc-website`.
3. Upload all files in this folder.
4. Go to Settings → Pages.
5. Under "Build and deployment," select "Deploy from a branch."
6. Select the `main` branch and `/root` folder.
7. Save. GitHub will give you a free website URL.

## Custom domain
After GitHub Pages is live, connect your domain by adding it in GitHub Pages settings and updating your domain DNS records.
